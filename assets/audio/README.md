# assets/audio

The "Free practice" card in the "Practise with Tezpha" section plays one file:

    assets/audio/free-practice.mp3

It does not exist yet. Until it does, the page hides the player and shows:
"A guided rest recording is on its way. Until then, begin with the videos above."
Drop the file in with exactly this name and the player appears; no code change is needed.

## Expected format

- A short guided Yoga Nidra / breath practice, recorded by Tezpha.
- MP3, mono, 64–96 kbps (constant or VBR), 44.1 kHz.
- Leave a second or two of silence at the start and end; no music bed is needed.
- Keep the file small (a 10-minute mono track at 80 kbps is about 6 MB).

If the title or length changes, update the card text in `index.html` (search for `free-practice`).
